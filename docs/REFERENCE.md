# 명령어 · 아이템 목록

플러그인이 제공하는 **명령어 30개**와 **특수 아이템 26종**을 한자리에 모은 표입니다. 찾아보기용이라 설명은 한 줄로 끊었습니다.

- 각 기능이 **무엇이고 왜 그렇게 동작하는지**는 [기능 설명서](FEATURES.md)에 있습니다.
- **설치와 설정 절차**는 [README](../README.md)에 있습니다.
- 여기 적힌 목록은 `src/main/resources/plugin.yml`과 `util/SpecialItemCatalog`에서 그대로 뽑은 것입니다. 둘 중 하나를 고치면 이 문서도 같이 고쳐야 합니다.

## 관리자 명령어

전부 `myminecraft.admin` 권한이 필요합니다 (기본값 OP).

| 명령어 | 사용법 | 하는 일 | 분야 |
|---|---|---|---|
| `/관리자메뉴` | `/관리자메뉴` | 관리자 안내·현황 GUI. 특수 아이템을 클릭으로 바로 지급 | admin |
| `/특수아이템소환` | `/특수아이템소환 <유저> <아이템명> <수량>` | 아래 [특수 아이템](#특수-아이템) 전부 지급 | admin |
| `/토큰암호화` | `/토큰암호화 <discord\|ai>` | `config.yml`의 평문 토큰·API 키를 `enc:` 형식으로 변환 | admin |
| `/스폰 설정` | `/스폰 설정` | 현재 위치를 스폰으로 지정 | world |
| `/로비 설정` | `/로비 설정` | 현재 위치를 로비로 지정 | world |
| `/초월제단설치` | `/초월제단설치` | 바라보는 블록 위에 초월의 제단 설치 | item |
| `/주식종류추가` | `/주식종류추가 <이름> <최소값> <최대값> <변동단위> <업종>` | 새 종목 추가 (시작가 = 최소값) | economy |
| `/주식지급` | `/주식지급 <종목명> <유저> <수량>` | 포인트 차감 없이 주식 지급 | economy |
| `/뉴스작성` | `/뉴스작성 <종목명> <상승\|하락> <변동폭%> <내용 또는 AI:주제>` | 진짜 뉴스 예약 (1시간 뒤 공개, 2시간 뒤 가격 반영) | economy |
| `/가짜뉴스작성` | `/가짜뉴스작성 <종목명> <상승\|하락> <변동폭%> <내용 또는 AI:주제>` | 가짜 뉴스 예약 (공개되지만 가격에는 무영향) | economy |
| `/팀생성` | `/팀생성 <팀이름> <팀장닉네임>` | 팀 생성 + 팀장에게 코어 1개 지급 | social |
| `/팀원추가` | `/팀원추가 <팀이름> <플레이어>` | 팀원 추가 | social |
| `/팀원삭제` | `/팀원삭제 <팀이름> <플레이어>` | 팀원 제외 (팀장은 불가) | social |
| `/팀삭제` | `/팀삭제 <팀이름>` | 팀 삭제 | social |
| `/레이드보스` | `/레이드보스 <소환\|제거\|목록> [보스ID]` | 레이드 보스 소환·제거·현황 | raid |

> 뉴스 명령어에서 내용 대신 `AI:주제`를 넣으면 Gemini가 본문을 씁니다. **등락 방향과 변동폭까지 생략**하면 AI가 종목 업종에 맞춰 그것까지 정합니다.

## 특수 아이템

`/특수아이템소환 <유저> <아이템명> <수량>` 의 **아이템명** 자리에 그대로 넣는 이름입니다. 관리자메뉴 GUI와 우편 첨부에서도 같은 이름을 씁니다.

### 무기 (7종)

| 아이템명 | 등급 | 한 줄 |
|---|---|---|
| `레바테인` | 신화 | 때릴수록 쌓이는 화염 지속피해. 라그나로크의 불은 물로도 안 꺼짐 |
| `드라켄피어스` | 신화 | 번개 연쇄 + 감전, 고정 방어관통 45% |
| `글레이프니르` | 신화 | **공격력 0**. 봉인·속박·절대봉인으로 상대를 묶음 |
| `사인참사검` | 신화 | 주변 적을 갉는 오라, 칠성강림 7연타 후 침묵+제압 |
| `발뭉` | 신화 | 상대 방어력이 높을수록 관통이 올라감 + 갑주 마모 |
| `자하신검` | 신화 | 이동속도↑, 평타 2회 판정, 저항·보호·방패 감면 무시 |
| `말룡도` | **전설** | 순서를 지켜야 열리는 3단 연계. 종말룡 드랍(기본 10%) |

### 강화 · 성장 (6종)

| 아이템명 | 한 줄 |
|---|---|
| `강화석` | 대장간 강화 재료. 시도할 때마다 필요 개수가 1개씩 증가 |
| `별가루` | 스타포스 재료. 성 1개당 별가루 1개, 최대 10성 |
| `일반두루마리` | 그 시도의 성공 확률 **+10%** |
| `레어두루마리` | **+20%** |
| `에픽두루마리` | **+30%** |
| `레전더리두루마리` | **+45%** |

### 암시장 (8종)

| 아이템명 | 한 줄 |
|---|---|
| `일괄약탈주문서` | 상자에 `웅크리기+우클릭` → 내용물을 한 번에 쓸어담음 (1개 소모) |
| `함정설치키트` | 상자에 우클릭으로 함정 설치. 설치자 외의 사람이 열면 독+위더 (또는 TNT) |
| `화염병` | 던진 자리에 불. 목재 건물 방화용 |
| `연막탄` | 던진 자리에 연막. 범위 안 대상 실명 |
| `밀도나침반` | 주변 청크에서 상자·화로류가 몰린 방향을 가리킴 (쿨타임 30초) |
| `발자국추적기` | 맞힌 플레이어가 이동할 때 흔적이 남음 (기본 3분) |
| `혈흔나침반` | 나를 죽이고 도망간 상대의 대략적 방향 (상대 접속 중일 때) |
| `소음차단포션` | 블록 파괴·상자 여는 소리가 주변에 전달되지 않음 (기본 30초) |

### 화폐 (5종)

포인트(G)를 실물로 바꾼 아이템입니다. **일반 아이템이라 플레이어끼리 주고받을 수 있습니다.**

| 아이템명 | 가치 |
|---|---|
| `1G` | 1G |
| `10G` | 10G |
| `100G` | 100G |
| `1000G` | 1,000G |
| `10000G` | 10,000G |

> 두루마리와 동전의 이름·개수는 `config.yml`의 `enhance.scrolls`와 `currency.coins`에서 나옵니다. 등급이나 단위를 추가하면 **이름도 따라서 늘어납니다** (두루마리는 표시명에서 "등급"과 공백을 뺀 형태, 동전은 `<값>G`).

## 권한

| 권한 | 기본값 | 범위 |
|---|---|---|
| `myminecraft.admin` | `op` | 위 [관리자 명령어](#관리자-명령어) 전부, `/스폰 설정`·`/로비 설정`, PvP 전투 중 명령어 차단 면제 |

OP는 이와 별개로 **이 플러그인이 거는 모든 부정적 효과에서 면제**됩니다 (화상·감전·함정·레이드 보스 패턴·현상금 표식 등). 자세한 내용은 [기능 설명서의 OP 면역](FEATURES.md#op-면역)을 보세요.

## 레이드 보스 ID

`/레이드보스 소환 <보스ID>` 에 넣는 값입니다.

| 보스ID | 이름 | 한 줄 |
|---|---|---|
| `eternal-knight` | 끝없는 기사 | 체력이 0이 되면 쓰러지며 영혼의 파편을 떨굼. 제한 시간 안에 전부 부숴야 진짜 처치 |
| `oblivion` | 기억할 수 없는 자 | 정면에서 오래 쳐다보면 행동 불능. 측면·후방에서 공격해야 함 |
| `apocalypse-dragon` | 종말룡 엔더드래곤 | 체력 1200의 파괴신형. 처치 시 기본 10%로 `말룡도` 드랍 |

## 설정 항목

`config.yml`의 최상위 항목입니다. 수치의 의미는 파일 안 주석에 적혀 있습니다.

| 항목 | 무엇을 조정하나 |
|---|---|
| `economy` | 시작 잔액, 재화 이름(G) |
| `currency` | 동전 종류와 가치 |
| `stock` | 주식 갱신 주기 등 |
| `news` / `ai` | 뉴스 공개·반영 지연, Gemini API 설정 |
| `enhance` | 강화 확률·비용·두루마리 등급 |
| `starforce` | 성당 방어관통, 최대 성 |
| `transcend-altar` | 초월의 제단 모델·동작 |
| `blackmarket` | 암시장 아이템 동작 (함정 모드 등) |
| `core` | 코어(팀 거점) 상점 가격 |
| `home` / `tpa` / `randomtp` | 홈 개수, 요청 만료, 랜덤이동 범위·쿨타임 |
| `combat` | PvP 전투 태그 시간, 전투 음악 |
| `combat-stance` | 전투모드 슬롯 아이콘·이름 |
| `bounty` | 현상금 표식 수치·이동 쿨타임·on/off |
| `laevateinn` `draken-pierce` `gleipnir` `sainchamsagum` `balmung` `jaha-shingeom` `malyongdo` | 무기별 피해·쿨타임·범위 |
| `raid-boss` | 보스별 체력·패턴 수치 |
| `discord` | 봇 토큰, 침입 알림 |
| `mail` | 우편함 상한, 보관 기간 |
| `web-bridge` / `activity-log` | 웹 관리 통로, 활동 기록 |

## 저장되는 파일

전부 `plugins/MyMinecraft/` 아래에 생깁니다.

| 파일 | 담는 것 |
|---|---|
| `economy.yml` | 플레이어별 포인트 잔액 |
| `homes.yml` | 플레이어별 홈 좌표 |
| `locations.yml` | 서버 공용 스폰·로비 좌표 |
| `teams.yml` | 팀 구성과 거점 |
| `stockdata.yml` | 종목과 마지막 가격·갱신 일정 |
| `stockholdings.yml` | 플레이어별 보유 주식 |
| `news.yml` | 예약된 뉴스 |
| `discord-links.yml` | 마인크래프트 ↔ 디스코드 연동 |
| `bounty.yml` | 현상금 표식 (누가 누구를 찍었는지) |
| `counter.yml` | 우편 번호 등 내부 카운터 |
| `mail/` | 플레이어별 우편함 |
| `logs/` | 거래 기록·활동 기록 (`trade-날짜.jsonl` 등) |

> 서버를 끄고 파일을 지우면 해당 기능의 기록이 초기화됩니다. **`economy.yml`·`stockholdings.yml`·`mail/`은 플레이어 재산**이므로 지우기 전에 백업하세요.
